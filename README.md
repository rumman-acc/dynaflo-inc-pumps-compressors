# Dynaflo, Inc. — Website

This is a single-page static website for Dynaflo, Inc., a Pennsylvania-based manufacturer of custom energy-efficient mini diaphragm vacuum pumps and air compressors.

## Overview

This website is built as a single self-contained `index.html` file with all styles inline. It requires no build process, no external dependencies (except Google Fonts), and no JavaScript.

## Features

- Fully responsive design
- Accessible HTML5 semantic markup
- Sections: Header, Hero, About, Products & Services, Differentiators, Contact, Footer
- Optimized for performance and SEO

## Deployment

To deploy this website:

1. Upload the `index.html` file to any web server or static hosting service
2. No build step or configuration required
3. Compatible with: GitHub Pages, Netlify, Vercel, AWS S3, or any standard web hosting

The page works immediately when opened in any modern web browser.

## Technology

- HTML5
- CSS3 (inline styles)
- Google Fonts (Inter)
- No JavaScript required
